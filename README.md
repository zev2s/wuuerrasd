# Кадр

Одностраничный сайт для скачивания прямых ссылок на видеофайлы, которые пользователь вправе сохранять. Вставьте прямую ссылку на файл `.mp4`, `.webm`, `.mov`, `.m4v` или `.mkv`.

Сайт не загружает видео с YouTube и других страниц видеосервисов, не изменяет качество файла и не проксирует содержимое. Браузер открывает исходную ссылку; фактическое скачивание зависит от настроек браузера и заголовков сервера, который размещает видео. Некоторые серверы блокируют скачивание или доступ с других сайтов.

## Локальный запуск

Откройте `index.html` в современном браузере. Сборка и сервер не требуются.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий.
2. Загрузите `index.html` в корень репозитория.
3. В настройках репозитория откройте **Pages** и выберите публикацию из ветки `main`, папка `/ (root)`.
4. После завершения сборки GitHub покажет адрес опубликованной страницы в разделе **Pages**.
